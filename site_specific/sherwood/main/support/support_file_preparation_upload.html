Project File Formats:

Preferred Project File Format:

Adobe® PDF® (Portable Document Format)

Acceptable Project File Formats include:

  • QuarkXPress®
  • Adobe® InDesign®
  • Adobe® Illustrator®
  • Adobe® Photoshop®

Possible Project File Formats:

  • CorelDRAW® (xxx.cdr)
  • Adobe® PageMaker® (xxx.pm)
  • Macromedia® FreeHand®
  • Microsoft® Publisher, Powerpoint, Word, or Excel files (xxx.pub; xxx.ppt(s); xxx.doc; xxx.xls)

*Note - additional charges may apply for converting "Acceptable and Possible Project File Formats" to our "Preferred Project File Format" of PDF in order to ensure efficient and accurate production of your project(s). "Possible File Formats" are dependant on the type of printing required and version of software used to create the project file(s).

Project File Preparation Instructions:

The following project file check list has been provided to help us minimize turn around time and help you avoid additional prepress charges.

  1. Include all "linked" graphics in proper colour format and appropriate resolution.

    • Appropriate Resolution
      • Commonly 300DPI or twice the line screen for Offset and Digital Offset Printing
      • Commonly 100-150DPI for Large Format Inkjet Printing
      • Commonly 100-300DPI or for Digital Printing

    • Proper Colour Format
      • CMYK for Process Ink Colour or Digital Printing Projects
      • Pantone Matching System Colours for Spot Colour Ink Printing Projects

        *Note - Please print your own colour separations when possible prior to uploading project files for production to ensure your expected results when printing with spot colour inks.

  2. Outline, Convert to Curves or Paths or Embed all Fonts (If Fonts are not outlined or embedded they may need to be supplied).
  3. Include all Bleeds(Commonly 1/8" or 1/16").
  4. Include Trim, Fold, Score and Perforation Marks when necessary.
  5. Include die lines when necessary.
  6. Ship Inkjet or Laser proofs or mock ups when possible.

Project File Upload Instructions

Project files may be uploaded once an order has been placed by clicking on the "Project Files" button located near the top right of the "Project View Current Project" page.

  1. Once on the "Project Files" page, click on the "Browse" button below to select files to upload from your own computer or network.

    If you are not uploading PDF files, please compress all folders, files and fonts when possible using common compression programs such as Win Zip or Stuff-It before uploading.

  2. Provide a description for your files to help us identify specific modifications, versions or instructions.
