Please read Sherwood Printers' project file preparation and approval instructions below before uploading project files for production.

Preferred Project File Format:

Adobe® PDF® (Portable Document Format)

Acceptable Project File Formats:

QuarkXPress® Adobe® InDesign® Adobe® Illustrator® Adobe® Photoshop®

Possible Project File Formats:

CorelDRAW® (xxx.cdr) Adobe® PageMaker® (xxx.pm) Macromedia® FreeHand® Microsoft® Publisher, Powerpoint, Word, or Excel files (xxx.pub; xxx.ppt(s); xxx.doc; xxx.xls) Note – additional charges may apply for converting "Acceptable and Possible Project File Formats" to our "Preferred Project File Format" of PDF in order to ensure efficient and accurate production of your project(s). "Possible File Formats" are dependant on the type of printing required and version of software used to create the project file(s).

Project File Preparation Instructions:

The following project file check list has been provided to help us minimize turn around time and help you avoid additional prepress charges. Include all "linked" graphics in proper colour format and appropriate resolution Appropriate Resolution Commonly 300DPI or twice the line screen for Offset and Digital Offset Printing Commonly 100-150DPI for Large Format Inkjet Printing Commonly 100-300DPI or for Digital Printing Colour Format CMYK for Process Ink Colour or Digital Printing Projects Pantone Matching System Colours for Spot Colour Ink Printing Projects Note – Please print your own colour separations when possible prior to uploading project files for production to ensure your expected results when printing with spot colour inks. Fonts, Trim, Fold, Proofs Outline, Convert to Curves or Paths or Embed all Fonts (If Fonts are not outlined or embedded they may need to be supplied). Include all Bleeds(Commonly 1/8″ or 1/16″). Include Trim, Fold, Score and Perforation Marks when necessary. Include die lines when necessary. Ship Inkjet or Laser proofs or mock ups when possible.

Project File Upload Instructions

File Uploader: Project files may be uploaded once an order has been placed via your account (for orders placed using our online product selector and shopping cart). Once on the account page, click on "Uploader" and "Browse" button in pop-up window to select files to upload from your computer If you are not uploading PDF files, please compress all folders, files and fonts when possible using common compression programs such as Win Zip or Stuff-It before uploading. FTP Access: For direct orders (products not ordered via online shopping cart) click on FTP access link in home page. Enter username & password provided to you and upload the file after completing requested project information in FTP upload form. *Important Notes – To avoid any additional prepress charges, please check and proof read the file(s) for the correct content including: Text Information, Spelling, Grammar, Graphical Images, Colours, Design, Layout and File Format before uploading and approving files for production.
