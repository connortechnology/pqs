Stock » Add, Edit, Delete

To Add a new stock Select the stock from the Search List below that most closely resembles the stock you will be adding. Select the Copy Button. Make the necessary changes in the Paper Information and Paper Pricing fields and select the Save button.
Note: Adding a new stock will only recommend this stock for the current Project type. In order to recommend this stock for additional project types this must be done in the Administrator section Stock > Recommendations.

To Edit an existing stock Select the stock from the Search List below. Make the necessary changes in the Paper Information and Paper Pricing fields and select the Save button.

To Delete an existing stock Select the stock from the Search List below. Select the Delete Button.
Note: any previous projects or products that have this stock used will no longer work and will require a replacement stock to be selected.
