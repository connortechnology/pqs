Printing Instructions

Shipping labels print directly from this page. A Print Preview will display how the labels will print.

On this page, Shipping Labels with checked-off checkboxes will print, those without will not, allowing the correct number of labels to be printed without waste.

10 labels are printed per sheet. When printing 25 labels, 2 separate print commands need to be issued. With the first, With the first, print 2 copies of a full 10 label sheet, producing 20 shipping labels. Then, uncheck 5 checkboxes, issue another Print command through your web browser, and the 5 remaining labels with checks in their checkboxes will be printed – providing a total of 25 shipping labels.

If this is your first time printing labels, or your labels are not printing correctly, please be sure that printing scale is set to 100%, all margins are 0.5 inches (12.7 millimetres) and all header and footer information is blank. These settings are typically accessed from the File menu, under Page Setup.

Once in Page Setup:

  • Windows users with Microsoft Internet Explorer 6 will see their settings right away.
  • Windows users with Mozilla Firefox will need to click the "Margins & Header/Footer" tab.
  • Mac Users will need to select "Custom Paper Size" from "Settings", and set margins there.
