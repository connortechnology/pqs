Customer Selection

As an employee or administrator you may now move this order to a different customer account by selecting it from the pull down below. Any projects attached to this order will be moved into the selected customer's account history. Please note the shipping information will remain the same as originally entered. To edit this after moving accounts select the project ID above and select the shipping service name, edit the information and save the page. If it does not update onto the order page you will need to cancel and re-open your order to see your changes.
