Project Files and Proofs

Default project file format is Adobe PDF (Portable Document Format) unless specified otherwise. To avoid any additional file preparation charges please read and follow our file preparation instructions carefully. Project files may be uploaded once an order has been placed by clicking on the "Project Files" button located near the top right of the "Project View Current Project" page.
