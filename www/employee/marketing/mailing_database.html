Instructions

To set-up as Administrator:
Steps 1-5 are optional.

  • Step 1: Update your scrubbing data information into the rules.csv file in the mail_data directory.
  • Step 2: Save your File as rules.csv (for Windows Comma Delimited) and replace the file in the mail_data directoy.
  • Step 3: Add your mailing database .csv (for Windows Comma Delimited) file to the FTP under the mail_data directory in the dirty_in folder. This file CAN contain column headers, and will be stripped out during Pre-Scrub. Click to view a sample of a working Dirty In file.
  • Step 4: Push this button to clean the file.
    Pre-Scrub Data File
  • Step 5: Go to your FTP under the mail_data directory in the dirty_out folder to retrieve your file. Click to view a sample of a working Dirty Out file.

  • Step 6: Run your file in your Streetsweeper program.
  • Step 7: Add your Clean File from Streetsweeper as a .csv (for Windows Comma Delimited) to the FTP under the mail_data directory in the clean_in folder. This file CANNOT contain column headers. Data must be sorted with columns in this order:
    Location Name CustomerCode (No column name) suite CityName Province PostalCode Phone Recency MostRecentOrderDate DeliveryMinutes
    Records will be categorized based on "Recency" for new, late, lapse30, lapse60 and lapsed. These are not case sensitive but must contain an exact match for letters. Click to view a sample of a working Clean In file.
  • Step 8: Push this button to add those records to the mailing Database.
    Add Records to Database
    To see what's in the mailing Database go to Custom Reports and select "Marketing Data" then Show Results.
  • Step 9: Create a PDF Template and Upload into the software here. Template must contain the following Block Names: AddressLineA1, AddressLineB1, AddressLineC1, Locater. It may also contain any other optional blocked Fields but it must contain those 4 blocks.
  • Step 10: Make a predefined project in the system that contains "Mailing Flyer" in the project name.
  • Step 11: Attach your template to your predefined project to create a new project where the template is attached as data file
  • Step 12: Add a link to your Local Store Marketing to the Mailing Database to go to: /customers/products/local/mailing/start.html?asr=mailing;record_count=1
    Edit your HTML for your mailing to update the new Project ID and any corresponding artwork jpg images.

To use as a customer:

  • Step 1: Login as the Company you want
  • Step 2: Go To Local Store Marketing
  • Step 3: Select Mailing
  • Step 4: Select Late, New or Lapsed
  • Step 5: Select Artwork 1-4
  • Step 6: Enter Quantity and Select "Click Here to Order"
  • Step 7: On the Template Record Page, Fill in all Fields Except the Address Lines and Select Locater, then select Save and Continue.
  • Step 8: Add initials and Select Approve and Continue.
  • Step 9: Select Save and Continue
  • Step 10: Reply Yes or No to the Pop-up
  • Step 11: If No: Confirm Order Information, If Yes: Repeat steps 2-10
  • Step 12: Submit your Order
  • Step 13: Pay for your order if necessary
  • Step 14: Receive your Order Confirmation by Email
To use as a Admin:
  • Step 1: Receive your Order Confirmation by Email
  • Step 2: Go To your FTP "ftp_mail_data" to retrieve the PDF and CSV Files
