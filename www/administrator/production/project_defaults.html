Import / Export

Project Types files must be in a comma separated values (CSV) format. All columns must have titles as the first row of data will be treated as column titles, and hence will be ignored. Defaults with a specified project type will override a default with no project type. The columns must be in the following order:

Project Type ID(s), Field Name, Field Value

To Import a Project Types file: select "Browse" and select the file containing your new database. Click "Open", then click on "Import".

To Export a Project Types file: select "Export" and select "Open" this will download the Project Types file to your "Temporary Internet Files" folder and automatically open the file for you. You can then make any necessary changes and then import the file back in. You can then open this in a spreadsheet program such as Microsoft Excel™.
