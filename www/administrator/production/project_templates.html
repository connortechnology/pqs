Import / Export

Project Templates files must be in a comma separated values (CSV) format. All columns must have titles as the first row of data will be treated as column titles, and hence will be ignored. The columns must be in the following order:

Project ID, Project Template, Drop Down Finished Dimensions, Finished Width, Finished Height, Panels, Flat Width, Flat Height, Design Hours 1 Sided, Design Hours 2 Sided

To Import a Project Templates file: select "Browse" and select the file containing your new database. Click "Open", then click on "Import Templates ".

To Export a Project Templates file: select "Export Templates " and select "Open" this will download the Project Templates file to your "Temporary Internet Files" folder and automatically open the file for you. You can then make any necessary changes and then import the file back in. You can then open this in a spreadsheet program such as Microsoft Excel™.
