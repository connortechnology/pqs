Shipping Method

 


Details

 






Import / Export - Shipping Zones

Shipping Zones files must be in a comma separated values (CSV) format. All columns must have titles as the first row of data will be treated as column titles, and hence will be ignored. The columns must be in the following order:

Zone #, ID, Name, Description, Country

To Import a Shipping Zones file: select "Browse" and select the file containing your new database. Click "Open", then click on "Import Zones".

To Export a Shipping Zones file: select "Export Zones " and select "Open" this will download the Shipping Zones file to your "Temporary Internet Files" folder and automatically open the file for you. You can then make any necessary changes and then import the file back in. You can then open this in a spreadsheet program such as Microsoft Excel™.

Import / Export - Shipping Prices

 


Shipping Prices files must be in a comma separated values (CSV) format. All columns must have titles as the first row of data will be treated as column titles, and hence will be ignored. The columns must be in the following order:

From Zone, Destination Zone, Minimum Weight, Maximum Weight, Units, Cost, Markup

To Import a Shipping Prices file: select "Browse" and select the file containing your new database. Click "Open", then click on "Import Prices".

To Export a Shipping Prices file: select "Export Prices " and select "Open" this will download the Shipping Prices file to your "Temporary Internet Files" folder and automatically open the file for you. You can then make any necessary changes and then import the file back in. You can then open this in a spreadsheet program such as Microsoft Excel™.
