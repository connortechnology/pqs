Import / Export

Project Services files must be in a comma separated values (CSV) format. All columns must have titles as the first row of data will be treated as column titles, and hence will be ignored. The columns must be in the following order:

Project Type, Template Type, Service ID, Field Name, Field Value

To Import a Project Services file: select "Browse" and select the file containing your new database. Click "Open", then click on "Import Services".

To Export a Project Services file: select "Export Services" and select "Open" this will download the Project Services file to your "Temporary Internet Files" folder and automatically open the file for you. You can then make any necessary changes and then import the file back in. You can then open this in a spreadsheet program such as Microsoft Excel™.
