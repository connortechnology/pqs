Import / Export

Definition files must be in a comma separated values (CSV) format. All columns must have titles as the first row of data will be treated as column titles, and hence will be ignored. The columns must be in the following order:

PMSID, ServiceID, MaterialID, Colour Name

Click here to view an example of data in CSV format.

To Import a Definition file: select "Browse" and select the file containing your new database. Click "Open", then click on "Import s".

To Export a Colour Definition file: select "Export s" and select "Open" this will download the Definitions file to your "Temporary Internet Files" folder and automatically open the file for you. You can then make any necessary changes and then import the file back in. You can then open this in a spreadsheet program such as Microsoft Excel™.
