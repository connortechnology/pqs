Import / Export

Paper Definition files must be in a comma separated values (CSV) format. All columns must have titles as the first row of data will be treated as column titles, and hence will be ignored. The field order is irrelevant.

To Import a Paper Definitions file: Choose the type of paper you wish to import (by clicking on the appropriate radio button above), select "Browse" and select the file containing your new definitions. Click "Open", then click on "Import Paper".

To Export a Paper Definitions file: Choose the type of paper you wish to export (by clicking on the appropriate radio button above), select "Export Paper" and select "Open" this will download the Paper Definitions file to your "Temporary Internet Files" folder and automatically open the file for you. You can then make any necessary changes and then import the file back in. You can then open this in a spreadsheet program such as Microsoft Excel™.

Predeletion: If you want to wipe out all paper of the type you are importing, prior to import, you may do so by clicking on the corresponding checkbox; predeletion of stocks will also clear pricing for those stocks and you will be required to reprice your stocks with a pricing file. Clicking "Delete all current Stocks" will also delete recommendations & visibility.

Individual Stock Removal: If individual stocks are to be removed from the spreadsheet, type "DELETE" in the category column. Those stocks will be removed after the stock definitions file has been imported.
