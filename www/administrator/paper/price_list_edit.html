Import / Export

Paper Price List files must be in a comma separated values (CSV) format. All columns must have titles as the first row of data will be treated as column titles, and hence will be ignored. The columns must be in the following order:

Paper ID, Min, Max, Units, Cost (per 100lbs), Markup, Sale Price (per 100lbs), Discountable

To Import a Paper Price List file: select "Browse" and select the file containing your new database. Click "Open", then click on "Import Prices ".

To Export a Paper Price List file: select "Export Prices" and select "Open" this will download the Paper Price List file to your "Temporary Internet Files" folder and automatically open the file for you. You can then make any necessary changes and then import the file back in. You can then open this in a spreadsheet program such as Microsoft Excel™.
